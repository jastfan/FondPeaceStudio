# Antigravity Autonomous Agent Directives (GEMINI.md)

## Core Working Philosophy
- **Action-First & Zero Fluff:** Prioritize direct code edits, instant setup, and working implementations over lengthy explanations. Keep responses crisp and actionable.
- **Autonomous Self-Healing:** When encountering errors (ports, processes, imports, network), diagnose the root cause immediately, fix it, and verify without asking repetitive confirmation questions.
- **Multi-Device Parity:** Every application, UI, and server must work seamlessly across:
  - Windows Desktop (Standalone app window, silent launcher, desktop shortcut)
  - Mobile Phones & Tablets (Android Chrome, iOS Safari, PWA standalone, touch gestures)
  - Apple macOS & Linux (Cross-platform path detection)
- **Safe Lifecycle & Process Management:** Ensure background daemons and processes clean up properly without leaving orphaned ports or zombie processes.
- **Aesthetic Excellence:** Use modern glassmorphism, responsive viewports, clean gradients, and fluid typography. Never build generic or bare-bones UI.
